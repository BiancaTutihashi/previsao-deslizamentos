# 🌍 Previsão de Risco de Deslizamentos de Terra com Inteligência Artificial

Este repositório contém o código, a análise exploratória e os modelos de Machine Learning desenvolvidos no âmbito de pesquisas em Inteligência Artificial no **ICMC - USP (São Carlos)**, integrando a **Engenharia Mecatrônica** com a ciência de dados.

O objetivo principal deste projeto é desenvolver ferramentas preditivas robustas baseadas em **dados captados por sensores**, visando a mitigação de desastres naturais e a **proteção de vidas** através de sistemas de monitoramento inteligentes.

---

## 🧭 Sobre o Projeto
Deslizamentos de terra representam riscos severos para comunidades vulneráveis. Este projeto processa e analisa séries temporais e variáveis ambientais coletadas por **sensores de campo** para treinar algoritmos de aprendizado de máquina capazes de prever a probabilidade de eventos críticos em tempo hábil.

---

## 🛠️ Tecnologias e Ecossistema
O ecossistema utilizado para o tratamento dos dados de sensores e desenvolvimento dos modelos envolve:
- **Linguagem:** Python
- **Aquisição & Análise:** Tratamento de dados de sensores, séries temporais e variáveis físicas.
- **Ambiente de Pesquisa:** Spyder, Kaggle.
- **Controle e Auxílio:** GitHub Copilot para suporte ao desenvolvimento e versionamento via Git.
- **Organização:** Google Sheets para validações preliminares de dados experimentais.
